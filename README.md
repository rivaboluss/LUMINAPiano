# LUMINA 流光钢琴

在浏览器里演奏和观看的 MIDI 视觉钢琴。接上电钢琴，或导入一首 MIDI，音符会变成落到琴键上的瀑布流，并带上烟雾和粒子。

## 可以做什么

- 用 USB 电钢琴、电脑键盘或鼠标演奏
- 导入 MIDI，自由演奏、自动播放，或切到音游模式
- 分别给瀑布流和烟雾粒子选颜色
- 录下来导出 MIDI，也可以录画面、导出整曲视频

请使用 Chrome 或 Edge。电钢琴自己有声音时，可以关掉「电脑发声」。

## 直接下载

免安装发布版已经放在 [Releases](https://github.com/rivaboluss/LUMINAPiano/releases)。下载压缩包，解压后双击 `LUMINA 流光钢琴.exe`。

需要 Windows 10 或更新版本，以及 Chrome 或 Edge。第一次打开如果出现 SmartScreen，点「更多信息」，再点「仍要运行」。不需要安装 Node.js，也不需要联网。

## 开发版

想在本地构建开发版、改功能，建议用编程助手（Agent）协助安装依赖、启动和修改。把本仓库交给它即可。

自己动手的话，需要已安装 [Node.js](https://nodejs.org)。在项目目录执行：

```bash
npm install
npm run dev
```

浏览器会打开 http://127.0.0.1:5173/ 。
