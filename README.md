# LUMINA 流光钢琴

在浏览器里演奏和观看的 MIDI 视觉钢琴。接上电钢琴，或导入一首 MIDI，音符会变成落到琴键上的瀑布流，并带上烟雾和粒子。

## 可以做什么

- 用 USB 电钢琴、电脑键盘或鼠标演奏
- 导入 MIDI，自由演奏、自动播放，或切到音游模式自己打点
- 分别给瀑布流和烟雾粒子选颜色
- 录下来导出 MIDI，也可以录画面、导出整曲视频

请使用 Chrome 或 Edge。电钢琴自己有声音时，可以关掉「电脑发声」。

## 本地打开

需要已安装 [Node.js](https://nodejs.org)。

双击 `start.bat`，或在项目目录执行：

```bash
npm install
npm run dev
```

浏览器会打开 http://127.0.0.1:5173/ 。`打开发布版.bat` 会先构建，再用预览地址打开。
